# Тестування iPhone Web Push

**Статус: фізичний iPhone НЕ перевірявся.** Сценарій підготовлено; результати порожні.

Архітектура: PWA (`miniapp/webpush.html`, `sw.js`) → код підключення → `/pairweb КОД` → сервер шле через `pywebpush` (`airradar/delivery/webpush_push.py`, до 3 пристроїв). **VAPID private key** — тільки на сервері (`vapid_private.pem`, у `.gitignore`, у бекапі лише в зашифрованому архіві); у Pages іде тільки публічний `vapid.json`.
Вимоги iOS 16.4+, сайт додано «На екран Додому», дозвіл дається з жесту користувача.

| # | Крок | Очікування | Результат |
|---|---|---|---|
| 1 | Safari → Поділитися → На екран Додому | іконка PWA | ⏳ |
| 2 | Відкрити з Home Screen → Увімкнути сповіщення | запит дозволу, код підключення | ⏳ |
| 3 | `/pairweb КОД` | бот підтверджує підписку | ⏳ |
| 4 | Тест-пуш (лише собі) | банер на локскріні | ⏳ |
| 5 | Тап по пушу | відкривається радар (`notificationclick`) | ⏳ |
| 6 | Застосунок закрито / телефон заблоковано | пуш приходить | ⏳ |
| 7 | Видалення PWA / скасування дозволу | наступна відправка → 404/410 → підписка видаляється | ⏳ (логіка в коді, живе не перевірялась) |
| 8 | Повторна підписка після оновлення сайту | працює | ⏳ |
Примітка: iOS може обмежувати фонову доставку; безпечна альтернатива — ntfy з App Store.
