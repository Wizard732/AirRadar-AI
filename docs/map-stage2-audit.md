Дата: 2026-10-31. Состояние: коммит `133e366` + правка нейтрального цвета моделей (см. п. 8).

## 1. Две карты, два набора данных
| | `miniapp/map.html` (1615 строк) | `miniapp/radar.html` (1292 строки) |
|---|---|---|
| Где живёт | основная карта бота (`/` и `/map` на сервере) | GitHub Pages (корень), APK |
| Данные | `/api/threats?minutes=120` (опрос) | `/api/tracks` + SSE `/api/stream`, резерв `tracks.json` |

Вывод: карты не используют общий код. Любая правка семантики цветов делается дважды.

## 2. Найденные дефекты
1. **`radar.html`: две функции `renderList`** (около строк 863 и 1047). Вторая перекрывает первую, первая — мёртвый код. Внутри мёртвой копии лежала логика окраски областей по типу угрозы — поэтому она не работала. Логика вынесена в `updateRegionKinds`; мёртвую копию нужно удалить отдельным шагом.
2. **Расхождение цветов между поверхностями** (до этой работы): `map.html` — дроны оранжевые, `radar.html` — дроны красные, ракеты фиолетовые. Сейчас: области — жёлтый (дроны) / красный (ракеты), модели нейтральные. Telegram-уведомления, Android, iPhone, статистика, админка — не проверялись.
3. **`map.html` не имеет полигонов областей/районов** — цвет области показывается кругом. Для пункта ТЗ 4.4 нужны полигоны и в этой карте.
4. **Нет фронтенд-тестов.** Проверка — только вручную через мок-сервер и `node --check`.

## 3. Безопасность публичных данных — требует решения владельца
`health_server._track_json` отдаёт в `/api/tracks` и `tracks.json`: `points` (координаты с 4 знаками), `now.lat/lon`, `speed_kmh`, `heading`, `forecast`, `dest`. `TRACKS_PUBLIC_DELAY_MIN` по умолчанию `0` (решение владельца). Это прямо противоречит разделу 5 ТЗ этапа 2 (публичная карта не раскрывает точные live-координаты, маршруты, скорость, курс). До решения владельца поведение API **не менялось**. Варианты: (а) публичный режим с агрегацией до района + задержкой, полный режим только админам; (б) оставить как есть и убрать пункт из ТЗ.

В предыдущей итерации модели были окрашены (дрон жёлтый, ракета красная). По описанию владельца и ТЗ этапа 2 цвет несёт область/район, а модель нейтральна. Модели возвращены к нейтральному светлому цвету в `radar.html` и `map.html`. Зоны/векторы в `map.html` сохраняют цвет типа.
