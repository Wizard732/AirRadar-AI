# AirRadar map2: дизайн-система и макеты (этап 2)

Выбрана концепция A+B: «Сцена + шторка» + постоянный блок «Моя територія». Макет: `miniapp/map2/mockup.html` (самодостаточный, без внешних библиотек, геометрия из `miniapp/raions.json`, **данные в макете условные**).

Открыть локально: `cd miniapp && python3 -m http.server 8765`, затем `http://localhost:8765/map2/mockup.html`.
Параметры: `?card=1` (карточка района), `?card=hint` (район с неофициальным сообщением), `?state=alert|offline|stale|loading`, `?sheet=peek|full` (mobile).

## 1. Принципы
1. Карта главная: на ней нет постоянных панелей шире 372 px (desktop) и выше 46% экрана (mobile).
2. Официальное и неофициальное различаются **формой, а не только цветом**:
   - официальная тревога: полупрозрачная заливка красным + сплошная граница + иконка сирены;
   - неофициальное сообщение: диагональная штриховка янтарём + пунктирная граница + иконка «!» + подпись «неофіційно» / «не підтверджено»;
   - нет данных / устарело: серый, подпись, без заливки.
3. Ответ на «у меня тревога?» виден без действий: блок «Моя територія» в верхней строке.
4. Любая панель закрывается, любая кнопка имеет `aria-label` и `title`.

## 5. Движок карты: сравнение для AirRadar
Текущее: Leaflet 1.9.4 (unpkg), полигоны районов из `raions.json` (139 районов, 267 КБ), без анимации объектов.
| Критерий | Leaflet (SVG/Canvas) | MapLibre GL |
|---|---|---|
| Вес библиотеки (gzip, порядок величины) | ≈40 КБ | ≈200 КБ |
| Рендер | SVG/Canvas, достаточно для ~139 полигонов + 27 областей | WebGL, избыточно для нашего объёма |
| Старые Android WebView / APK, Telegram iOS | стабильно | WebGL-контекст может падать/теряться; нужен fallback |
| Заливки/штриховка | SVG pattern, легко (как в макете) | через `fill-pattern` + спрайт, сложнее |
| Плавный зум, наклон, 3D (GLB-предложение) | рывками, без наклона | плавно, есть |
| Векторные подложки | плагины | нативно |
| Offline-кэш тайлов | проще | сложнее |
| Миграция | уже используется, меньше риска | переписать слой геометрии и подписей |
**Рекомендация:** для этапов 3–8 остаёмся на Leaflet (Canvas-рендерер для полигонов) за интерфейсом `map/layers.js` (`setStatus(districtId, state)`, `flyTo`, `setBasemap`, `onSelect`). Пока на карте только территориальные заливки без движущихся объектов, MapLibre не даёт видимого выигрыша, но добавляет вес и риск WebGL на старых устройствах. Пересмотреть при внедрении GLB/3D-слоя или векторной подложки; абстракция `layers.js` позволит заменить движок без изменения UI. Цифры веса приблизительные; перед решением замерить сборкой.

## 6. Совместимость (оценка по макету, на этапе 2 без интеграции)
- Mini App: интерфейс использует только CSS/SVG, `safe-area-inset-*`, `dvh`-независимую раскладку; fullscreen через Telegram API с fallback будет на этапе 3.
- APK: файлы `miniapp/map2/*` добавляются в `npm run sync`; внешних шрифтов и CDN в макете нет.
- Service worker: новые файлы в precache на этапе 3.

## 7. Что не сделано / ограничения
- Макет статичный: поиск, фильтры, вкладки «Історія» и «Фільтри», геолокация, слои не работают, только оформление.
- Данные в макете условные, API не вызывается.
- Скриншоты 1440×900 и 375×812 просмотрены в панели браузера; в репозиторий как файлы не сохранены (нет headless-Chrome на машине).
- Проверка скринридером и контраста по WCAG не проводилась.

## 8. Известные ограничения источника (этап 5)
- **Киев и Київська область, Севастополь и Крим.** Официальный источник (`sirens.py`, `ALERTS_IN_UA_REGION_IDS`: id 11 → `kyivska`, id 20 → `crimea`) не имеет отдельного идентификатора для города. Тревога города приходит как `kyivska` или `crimea`, поэтому подсвечиваются **обе** территории (город и область, Севастополь и Крим). Это не точное разделение городской тревоги. В интерфейсе это обозначено заметкой в карточке активной тревоги; в коде комментарий в `data.js` (`CITY_IN_SLUG`). Точное разделение требует отдельного признака в `official` на стороне бэкенда.
- **Поиск** находит области и районы (по `raions.json`), но не города и сёла: на клиенте нет геокодера.
- **Фильтры** действуют на карту и список; карточка территории всегда показывает реальное состояние независимо от фильтров. Фильтры сохраняются в `localStorage` этого браузера.
- **Подложки** Esri бесплатны для умеренной нагрузки, для большого трафика нужна лицензия или собственная подложка.

## 9. Мобильная версия (этап 6)
- **Раскладки:** `desktop` (≥900 px), `mobile` (портрет, нижняя шторка), `land` (ландшафт телефона: высота ≤500, ширина <1000, боковая шторка 320 px). Выбор в `app.js` (`layout()`) и в `map2.css` (media-запросы).
- **Шторка:** peek 132 px / half 46% / full 84%; перетягивание за ручку (36 px) и строку вкладок; привязка к ближайшему состоянию, быстрый свайп (>0,4 px/мс) переключает на соседнее; тап по ручке и стрелки ↑/↓ меняют состояние. Состояние шторки меняет только пользователь: фильтры, поиск и обновление данных его не трогают. Карточка скрывает шторку и при закрытии возвращает её в прежнее состояние; фокус возвращается на элемент, открывший карточку.
- **Карта:** resize и поворот пересчитывают размер без `fit`, если пользователь уже двигал карту (адресная строка браузера тоже вызывает resize); пока не двигал, вид подгоняется под новую раскладку. Перетягивание шторки карту не перерисовывает (только `--sheetH` для позиции инструментов).
- **Safe-area:** `--sat/--sab/--sal/--sar` = `env(safe-area-inset-*)`; в Telegram Mini App поверх берутся `safeAreaInset` и `contentSafeAreaInset` (Bot API 8.0+, `max(...)`), события `viewportChanged/safeAreaChanged/fullscreenChanged`. `--vvh` из `visualViewport` ограничивает список результатов поиска при открытой клавиатуре.
- **Контраст:** текстовые токены ≥4,5:1 на `surface` и `surface-2` в тёмной и светлой темах (проверяет `test_map2_a11y.py`). Исправлены `faint` и `nodata`; в светлой теме отдельные тёмные значения `alert/hint/ok/focus`.
- **Цели касания:** ≥44 px (чипы, вкладки, закрытие карточки, строки списка, поле поиска как обёртка); исключения: кнопки инструментов 40 px на экранах ниже 720 px и в ландшафте (иначе колонка не помещается рядом с карточкой), WCAG 2.2 AA требует ≥24 px.
- **Reduced motion:** CSS отключает анимации; перелёты карты заменяются на мгновенный `fitBounds`.
- **Ручная проверка:** `test/probe.js` (загрузка через `eval(await (await fetch('/map2/test/probe.js')).text())`) проверяет выход за экран, перекрытия, цели касания и сценарий «строка → карточка → закрытие».

## 10. Надійність даних, offline і Service Worker (етап 7)
**Модулі.** `sync.js` (транспорт, чиста логіка з підміною env, тестується в node), `data.js` (адаптер публічного контракту поверх `DataSync`), `sw.js` + `sw-rules.js` (окремий Service Worker карти зі scope `map2/`). Основний `miniapp/sw.js` НЕ змінено: SW карти має вужчий scope, тож для сторінок `map2/` керує саме він, для решти застосунку нічого не змінюється.

**Стани зв'язку:** `loading → ok | error | offline`, `offline → recovered (4 с) → ok`. `error` лише коли немає ні мережі, ні придатних збережених даних: тоді екран помилки з причиною («немає інтернету» / «дані не завантажились») і кнопкою «Повторити», порожня карта за «тривог немає» не видається. `offline` = показані збережені дані з явною плашкою «Показано збережені дані, оновлені N тому» (оновлюється кожні 15 с) і сірим індикатором свіжості.

**Опитування і SSE.** Один запит одночасно (single-flight; запит під час запиту = один повтор після нього). Один таймер-ланцюжок: 60 с при живому SSE, 30 с без нього, 60 с у статичному режимі (Pages). Помилки: backoff 10→20→40→80→120 с (±20%), `online`/«Повторити»/повернення на вкладку скидають лічильник. Прихована вкладка не опитує. SSE: повторний `rev` ігнорується, `rev` запам'ятовується лише після успішного завантаження; після розриву і `onopen` робиться повна синхронізація даних і історії; якщо браузер закрив потік остаточно, перевідкриття з backoff; `stop()` знімає таймери, EventSource і слухачі, повторний `start()` не дублює обробники. Відповідь з меншим `updated_at`, ніж уже застосований, відкидається.

**Кеш даних (не Service Worker).** `localStorage`: `{v:2, savedAt, raw}` для контракту, окремо журнал. Кеш старший за 6 год не використовується і видаляється. Дані тривог навмисно НЕ в Service Worker: вчорашній статус не може виглядати поточним, вік показується завжди, а `stale` (>15 хв від `updated_at`) приглушує заливки і пише «Орієнтуйтесь на сирену».

**Service Worker.** Precache: код карти, `../raions.json`, Leaflet (CDN необов'язковий, не блокує встановлення). Код: network-first з таймаутом 3,5 с і запасним кешем; Leaflet: cache-first (версія зафіксована в URL). Ніколи не кешується і не перехоплюється: `/api/*`, `public-regions.json`, `alerts_hist.json`, `tracks.json`, `/admin*`, `/health`, push, тайли карти та інші домени. Версія кешу `airradar-map2-<VERSION>` у `sw-rules.js`; при активації видаляються лише старі кеші `airradar-map2-*`, кеш основного застосунку не чіпається.

**Помилка історії** не ламає карту: лишається попередній журнал з прапором `error`, у вкладці «Історія» нотатка «Журнал не оновився N тому. Час і тривалість можуть бути неактуальними».

**Перевірка.** У вбудованому браузері панелі реєстрація SW неможлива, тож крім node-тестів SW перевірено в реальному Firefox (headless, localhost): install/activate, offline-запуск, оновлення версії, співіснування з основним `sw.js`. Основний `sw.js` при активації видаляє всі чужі кеші, тому `map2/sw.js` один раз за життя самовідновлює свій кеш, якщо його немає. Відповіді сервера 5xx трактуються як відсутність мережі. На iOS/Android/Telegram WebView не перевірялось (там кеш SW і localStorage можуть очищатися системою). Обов'язково перевірити на пристроях перед інтеграцією: перший запуск без інтернету, повторний із кешем, оновлення версії SW, поведінка SSE за мобільної мережі.
