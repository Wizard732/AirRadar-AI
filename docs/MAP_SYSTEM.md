# Система карти

## Джерела та оновлення (перевірено в коді)
- Живий API бота `/api/tracks?minutes=N` (`health_server.radar_payload`), опитування клієнтом кожні ~15–30 с; WebSocket/SSE немає.
- GitHub Pages: статичний `tracks.json` (ветка `radar-data`, сервер пушить раз на ~2 хв, `airradar-radar-publish.timer`). Клієнт на `github.io` одразу йде на статику.
- Єдиний цикл опитування, оновлення замінює набір (без дублікатів маркерів); при відновленні мережі наступний poll повністю синхронізує стан із сервером.

## Не виконано (потребує окремої роботи/перевірки в браузері)
Фільтр за статусом/часом на карті (є категорії `hiddenCats` і часова шкала ⏱); пошук саме населених пунктів (зараз райони/області — gazetteer на 51 тис. записів у браузер не вантажиться); окремі перемикачі всіх шарів; **оновлення** gazetteer/укриттів з зовнішнього джерела (скрипти `build_gazetteer.py`/`build_shelters.py` існують, потребують мережі/ліцензії OSM/GeoNames і запуску власником, після чого — `scripts/check_geo_data.py --write-clean`); «відкрито/доступно» для укриттів джерело не підтверджує — у відповідях лишається дата даних.

## Політика даних
Публічний текст проходить `fast_filter.public_text` і `safety_policy`; точні координати об'єктів ППО/військових не публікуються (`_COORDS` у safety_policy блокує координати в тексті). Нагадування: затримка за замовчуванням 0 за рішенням власника — для стримування змініть `TRACKS_PUBLIC_DELAY_MIN`.
