# Аудит `impacts.json` (наслідки/прильоти)

Статус: аудит и безопасный вариант подготовлены, **production не менялся.** Подключение — только после согласования.

## 1. Что содержит
| Поле | Пример (синтетика) | Чувствительность |
|---|---|---|
| `ts` | 1700000123 (до секунды) | точное время события |
| `oblast`, `slug` | Київська | область — приемлемо |
| `place` | название города | **город** места события |
| `lat`, `lon` | 50.4501, 30.5234 | **координаты города** (`precision: place`) или центра области (`oblast`) |
| `killed`, `injured`, `children` | числа из текста сообщений | гуманитарные данные, неофициальные |
| `damage` | категории («житлові будинки», «енергетика») | общая категория; адреса и названия объектов не сохраняются |
| `kind` | `hit` / `heard` | попадание или «слышно» |
| `totals`, `note` | агрегаты | безопасно |

## 2. Откуда берётся
`impact_log.record()` разбирает сообщения мониторинговых каналов; место определяется геокодером (`_where`): город (`precision: place`) или центр области (`oblast`). Адреса и названия объектов отбрасываются; числа жертв берутся только из явных чисел текста.

## 3. Хранение и публикация
- БД: таблица `impact_reports`, без срока хранения (долговременный журнал).
- `impacts.json`: последние 14 суток, до 300 записей; пишет `export_radar.py` в ветку `radar-data` (одним коммитом, force-push), раздаётся GitHub Pages (`/impacts.json`).
- Задержка: `IMPACT_DELAY_MIN` (по умолчанию `DEFAULT_DELAY_S = 0` — решение владельца).
- Тот же список попадает в `/api/tracks` как `impacts` (последние 6 часов, `radar_payload`), и клиент рисует их точками (`radar.html`).
- Копии: старые деплои Pages и кэш CDN; ветка `radar-data` перезаписывается, но у GitHub возможны сохранённые артефакты.

## 4. Что можно восстановить
По публичным данным восстанавливается **город и время (до секунды) каждого попадания**, их последовательность и география за 14 суток. Это уровень «место и момент попадания» — информация, полезная для оценки результативности ударов. Адреса и объекты не публикуются, но город + время + категория повреждений («энергетика») уже достаточно детальны.

## 5. Безопасный вариант (реализован в коде, не подключён)
`airradar/safety/public_view.public_impacts(payload, delay_min=180)`:
- город (`place`) убран, `lat/lon = null`, `precision = "oblast"`;
- время округляется до 30 минут;
- записи свежее 180 минут не публикуются;
- `totals`, число жертв, категории и `kind` сохраняются (общая картина без привязки к месту).
Клиент `radar.html` уже пропускает записи без координат (на карте точки нет, остаётся список/счётчики по областям).

## 6. Варианты решения для владельца
1. **Агрегация по области + задержка 180 мин** (реализовано) — публичная карта показывает «наслідки по областях», без города и без секунд.
2. Оставить как есть (город, время) — требует прямого решения владельца и сознательного риска.
3. Закрыть `impacts.json` для публики; детальный журнал — только админам.
Рекомендация: п.1.

## 7. Что нужно для подключения
1. Согласование владельца.
2. `export_radar.py`: `impacts.json = public_impacts(impacts_payload(...))`; `radar_payload`/`/api/tracks`: то же для поля `impacts`.
3. Удаление старых артефактов: пересоздать `radar-data` (orphan) и дождаться пересборки Pages; кэш CDN истекает по TTL.
4. Тесты на отсутствие `place`, `lat`, `lon` в публичных ответах (есть для функции, добавить для endpoint).
