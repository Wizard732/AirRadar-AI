# AirRadar: исследование референсов для новой карты

Дата: 2026-11-03. Этап 1 ТЗ «новая карта с нуля». Только функции и сценарии; интерфейс, иконки, тексты, цвета референсов не переносим.
Дополняет `docs/neptun-reference-study.md` (подробный разбор NEPTUN от 2026-10-31).

## 1. DIMAP.LIVE
Наблюдаемое на странице (mobile, 2026-11-03):
- Карта на весь экран, тёмный спутник/схема, контуры областей, масштабная линейка.
- Верх: выбор языка и «Усі регіони», индикатор связи (задержка в мс, «Чудове з'єднання»).
- Право: вертикальный стек инструментов (маршрутизация, полный экран, геолокация, снимок, зум ±, «моё местоположение»).
- Низ: плавающая навигация «Мапа / Канал / Підтрим. / Налашт.». Вкладка «Канал» — лента сообщений источников.
- Настройки открываются панелью с разделами: Карта, Шари, Цілі, Сітки, Навігація, Сповіщення, TV режим.
- Метка «БЕТА» с честным предупреждением о неточностях и задержках; легенда «Типи цілей».
- Атрибуция источников данных внизу (карта OpenFreeMap/OSM, окупация DeepState).

Сценарии, которые стоит реализовать у себя:
1. Выбор региона («Усі регіони» → область) и запоминание выбора.
2. Раздельные слои (тревоги, цели, сетки) с независимым включением.
3. Индикатор качества связи и свежести данных.
4. Режим «TV» (крупная карта для экрана без управления).
5. Ссылка на канал/ленту как отдельная вкладка, а не часть карты.
6. Явная атрибуция и метка «бета».

## 2. NEPTUN (кратко, см. отдельный документ)
Сценарии: панель «Обстановка» с группировкой по областям и чипами категорий; «Останні оновлення»; карточка района (тревога с HH:MM, длительность, уровень, тип); заливки областей; обновление существующих отметок вместо дублей; загрузочный экран; промо-окна (не берём).

## 3. Сводка функций → решение для AirRadar
| Функция | DIMAP | NEPTUN | AirRadar |
|---|---|---|---|
| Контуры областей/районов, заливка по тревоге | да | да | да (`raions.json`, области) |
| Поиск города/района | нет | да | да |
| Карточка территории | частично | да | да: официальная тревога отдельно от неофициальных сообщений |
| Лента событий | вкладка «Канал» | «Останні оновлення» | да, хронология с устареванием |
| Фильтры категорий | да | чипы | да |
| Подложка | схема/спутник | спутник/схема | тёмная схема, спутник, светлая |
| Полный экран, геолокация | да | да | да |
| Offline/ошибка/восстановление | индикатор связи | загрузочный экран | да (есть этап 4 прошлой итерации) |
| Точные координаты, курс, скорость, ETA целей | да | да | **не в публичном клиенте** (см. §5) |
| Рекламные баннеры, промо | да | да | нет |

## 4. Что уже есть в AirRadar и переиспользуется
- Данные: `/api/public/v1/regions` (район/область, категория, статус, диапазон количества, время с задержкой, без координат), `/api/tracks` (публичное представление через `public_view`), `/api/alerts-history`, `/api/stats`, SSE `/api/stream` (только `rev` + heartbeat).
- Официальные тревоги: `sirens.py` (alerts.in.ua: `active_alert_slugs`, `active_raion_keys`, `alert_details`), `alarm_notices.py`.
- Геоданные: `miniapp/raions.json` (267 КБ).
- Клиенты: Mini App `app.html` (iframe), APK `app/www`, Pages, сервер `/radar`, `/`, `/map` (см. `docs/map-clients.md`). Сохраняем контракт загрузки: `radar.html`/`map.html` остаются, пока новая карта не пройдёт приёмку.
- Service worker `sw.js`, `native.js` (мост для APK).

## 5. Данные: что показывает публичная карта
Новая карта строится на **публичном контракте** (район/область, категория, статус, диапазон, округлённое время). Точные координаты, курс, скорость, прогнозы и ETA не используются в публичном клиенте. Полный режим остаётся отдельным закрытым источником за `X-Admin-Token` (`/admin/tracks`), клиент к нему не подключается. Это следует ТЗ архитектора. Ранее владелец решил включать полные данные по умолчанию (`PUBLIC_MODE` не задан): решение остаётся за владельцем и не меняется без его явного слова, новая карта это не вшивает: источник данных переключается одной настройкой адаптера.

## 6. Функциональные сценарии для реализации
1. Открыть карту → видно статус страны («N областей в тревоге»), свежесть данных.
2. Найти район/город → карта летит к территории → карточка.
3. Тап по территории → карточка: официальная тревога (старт, длительность, тип) и отдельным блоком «Неофициальные сообщения» (категория, диапазон, время).
4. Открыть ленту → хронология, обновление без скачков, устаревшее выделено.
5. Фильтры категорий и слоёв; переключение подложки без потери состояния.
6. Геолокация → статус моей территории.
7. Потеря связи → плашка и кэш; возврат → обновление.
8. Mobile: нижняя панель с тремя положениями; Desktop: боковая панель + карточка.
