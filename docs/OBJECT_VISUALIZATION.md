# Візуалізація об'єктів

## Поточний стан
- Об'єкт — SVG-силует із `ICO` у `miniapp/radar.html` (дрон, ракета, КАБ, авіація, FPV, РСЗО тощо). Окремого 3D-рендерингу немає, і його не додавали: навантаження на слабкі пристрої.
- Колір тіла визначається типом: `trackColor` — **дрон жовтий `#ffd60a`, ракета червона `#ff3b30`**. Свічення (`--glow`) бере той самий колір.
- Поворот: `transform: rotate(heading)`, якщо курс відомий; без курсу модель стоїть прямо (курс не вигадується).
- Застарілі цілі (`stale`) — сіра заливка та прозорість; анімація зупиняється.

## Семантика кольорів (нормалізований тип → клас → колір)
| Клас | Типи | Колір |
|---|---|---|
| drone | shahed, uav, recon_drone, fpv | `#ffd60a` жовтий |
| missile | cruise_missile, ballistic, missile, air_missile, coastal_missile | `#ff3b30` червоний |
| bomb | kab | `#ffb020` |
| aircraft | aviation, tac_aviation, strat_aviation | `#5ac8fa` |
| artillery | mlrs, artillery | `#ff9f0a` |
| other | невідомий тип | `#9aa3b5` (нейтральний, ніколи не дрон/ракета) |

Джерело істини для Python — `airradar/safety/object_lifecycle.py` (`KIND_CLASS`, `CLASS_COLOR`). У JS (`radar.html`) таблиця дублюється; при зміні треба правити обидва місця. Синхронізація Telegram, Android, iPhone, адмінки — **не зроблена**.

## Регіони з тривогою
- Область: `regionKind` — `m` (ракети) → червоний, `d` (дрони) → жовтий. Джерело — офіційні `threat:slug:тип`.
- Район: фарбується за типом його області (офіційні дані не дають типу на рівні району). Невідомий тип — лишається червоним, як звичайна повітряна тривога.
- Попередження (warning level) для районів теж жовтий — це збігається з кольором дронів.

## Чого немає
- 3D-моделі та їх оптимізація при віддаленні — не виконувались.
- Легенда з кольорами «жовтий — дрони / червоний — ракети» — не додана в інтерфейс.
- Mini App, Android, iPhone — не перевірялись на реальному пристрої.
