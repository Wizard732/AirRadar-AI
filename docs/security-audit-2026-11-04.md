## ⚠️ Критично: секрети в історії ПУБЛІЧНОГО репозиторію
Репозиторій `Wizard732/AirRadar-AI` публічний. В історії git (DEPLOY.md, коміт 2b86003 від 2026-08-01, прибрано в 2f59ef1) є
рядки, що виглядають як справжні **BOT_TOKEN** (формат `8560184184:AAH…`) та **TG_API_HASH**. З поточного дерева вони видалені,
але з історії доступні кожному.
**Що зробити власнику (я цього зробити не можу):**
1. @BotFather → `/revoke` для бота → новий токен → оновити `BOT_TOKEN` у серверному `.env`, перезапустити сервіс. Це знецінює витік.
2. `TG_API_HASH`: замінити неможливо без нового застосунку на my.telegram.org; саме по собі api_id+hash не дає доступу до акаунта,
   але перевірте Telegram → Налаштування → Пристрої (чужих сесій немає), увімкніть двоетапну перевірку на акаунті Telethon.
3. За бажання повністю прибрати з історії: `git filter-repo --replace-text` + force-push усіх гілок (руйнівна дія; кеші GitHub і
   форки можуть зберегти копії — тому пункт 1 обов'язковий, пункт 3 — косметика).
4. Увімкнути GitHub **Secret scanning + Push protection** (Settings → Code security) — безкоштовно для публічних репозиторіїв.

## Що вже було добре (перевірено)
- SQL: усі запити параметризовані, f-рядки — лише імена колонок із білих списків.
- Адмін-команди бота: кожна під `_is_admin`/`_is_super`; `give_admin` потребує підтвердження `/confirm_admin`.
- `/admin/*`: токен лише в заголовку, `hmac.compare_digest`, довжина ≥16, без токена — 404.
- Вихід ШІ перевіряється (`ai_guard.validate_output`), вхід очищається від prompt-injection; ШІ нічого не вирішує щодо прав.
- Бекапи шифруються (AES-256, pbkdf2 200k) і мають права 0600; ключі підпису APK (`*.jks`, `keystore.properties`), `.env`, `*.session` у `.gitignore` й не потрапили в коміти.
- Fuzz парсерів на 4096-символьних вхідних даних: решта шляхів < 0.1 с.

- [ ] Токен `gh` на Mac має зайві/недостатні права: створити fine-grained PAT лише для цього репозиторію (contents + pull requests).
- [ ] GitHub: 2FA, branch protection для `main` (деплой робить `git reset --hard origin/main` — будь-хто з правом запису в `main` фактично керує продом), Dependabot alerts, Secret scanning.
- [ ] Сервер: фаєрвол (без вхідних портів, лише тунель), `HTTP_BIND=127.0.0.1`, `TRUST_PROXY_HEADER` для вашого тунелю, `ADMIN_DASH_TOKEN` ≥ 16 символів, `chmod 600 .env`.
- [ ] Публічний режим (`PUBLIC_MODE=legacy`) віддає координати/курс цілей усім; це рішення власника — `PUBLIC_MODE=region` дає узагальнені дані.
